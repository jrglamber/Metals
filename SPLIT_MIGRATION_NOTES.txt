LIVE INDICES PROJECT

- Metals demo execution is hard-disabled even if stale METALS_DEMO_* Railway variables remain.
- Dashboard no longer renders the metals research/demo section.
- Signal coverage expects NAS100 + US500 only.

NEW METALS PROJECT
- Hard scope: XAUUSD + XAGUSD only.
- NAS100/US500 webhooks are ignored before DB insertion.
- Legacy/live index OANDA execution is hard-disabled in code.
- Uses ONLY the isolated METALS_DEMO_* OANDA practice lane.
- Both long and short simulation remain enabled.
- Short v1/v2 research remains available.
- 48h is the normal minimum hold / fixed benchmark.
- Every new hourly metal signal after 48h triggers manager review.
- 72/96/120h are protection milestones, not forced exits.
- XAU/XAG asset-side basket management remains separate.
- METALS_BASKET family overlay remains advisory.
- Close-until-flat action queue and broker audit remain active.
